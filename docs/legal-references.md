# Referências legais e de privacidade

O PixBee mantém uma página resumida de privacidade e direitos na rota `/privacidade`. Este arquivo registra as fontes públicas usadas como referência conceitual para transparência e autoria.

| Tema | Referência |
| --- | --- |
| Proteção de dados pessoais | [Lei Geral de Proteção de Dados Pessoais — Lei nº 13.709/2018](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm) |
| Direitos sobre software | [Lei do Software — Lei nº 9.609/1998](https://www.planalto.gov.br/ccivil_03/leis/l9609.htm) |
| Orientações institucionais | [Autoridade Nacional de Proteção de Dados](https://www.gov.br/anpd/pt-br) |

> Este material organiza informações gerais para o produto. Não substitui uma avaliação jurídica profissional, especialmente se o PixBee passar a tratar dados em servidor, tiver login, receber pagamentos ou for comercializado.
